# ASRBD - Atelier : Administration et Optimisation des données (`BDOE633`)

> [!INFO] Présentation du module
> - **Code :** `BDOE633` - **Volume :** 14 h
> - **Certification :** ASRBD / RNCP 41996 - Bloc `BC01` (*Administrer le Système d'Information*)
> - **Environnement de TP :** **SQL Server 2025 sous Debian 13** (1 VM par groupe)

## Compétences visées
- **`ASRBD1.7`** : Administrer les bases de données avec méthode (instances, paramètres, schémas, droits, stockages) en privilégiant les solutions économes en énergie.
- **`ASRBD1.8`** : Analyser les performances des bases installées à partir des rapports d'usage collectés pour accélérer les requêtes.
- **`ASRBD1.9`** : Optimiser l'emplacement des fichiers de stockage (données, journaux, index) sur les supports les plus adaptés.
